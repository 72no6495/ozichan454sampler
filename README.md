# Web Sampler & Sequencer

ブラウザ上で動作する高機能なサンプラーおよびシーケンサーです。GitHub Pagesなどの静的ホスティングサービスで公開可能です。

## 機能概要

### 編集モード (Edit Mode)
- **サンプルのロード**: ローカルの音声ファイル（WAV, MP3など）を読み込み可能。
- **波形表示**: 読み込んだ音声の波形を視覚化。
- **トリミング**: 開始位置（Start Offset）と終了位置（End Point）を指定して、必要な部分だけを再生。
- **パラメータ調整**:
  - Volume (音量)
  - Playback Rate (再生速度・ピッチ)

### 演奏モード (Performance Mode)
- **マルチトラックシーケンサー**: 複数の音声を同時にレイヤーしてリズムを作成。
- **ステップ入力**: 16ステップのグリッドをクリックしてパターンを作成。
- **ピッチ変更**:
  - **Shift + Click**: ステップのピッチを半音上げる
  - **Ctrl + Click**: ステップのピッチを半音下げる
- **BPM制御**: 再生テンポを自由に変更可能。

## 使い方

1. **システム起動**: 初回アクセス時、「システム起動」ボタンをクリックしてオーディオエンジンを開始してください。
2. **サンプル追加**:
   - 左側の「スロット追加」ボタンを押して空のスロットを作成。
   - スロットを選択し、中央上の「ファイル読込」から音声ファイルをアップロード。
3. **音作り**:
   - スライダーを使って音量や再生範囲を調整。「試聴」ボタンで確認。
4. **パターン作成**:
   - 右上の「演奏モード」をクリック。
   - 「トラック追加」で、現在選択されているサンプルをシーケンサーに追加。
   - グリッドをクリックしてリズムを打ち込みます。
5. **再生**: 上部の再生ボタンでシーケンスをループ再生します。

## 技術スタック

- **HTML5 / CSS3**
- **Tailwind CSS**: スタイリング
- **Tone.js**: Web Audio APIラッパー（音声処理の中核）
- **Vanilla JavaScript**: アプリケーションロジック

## インストール・公開方法

このリポジトリのファイル一式（`index.html`, `js/`, `css/`）をWebサーバーに配置するだけで動作します。ビルドプロセスは不要です。

### GitHub Pagesでの公開手順
1. このリポジトリをGitHubにプッシュ。
2. リポジトリの `Settings` -> `Pages` に移動。
3. `Branch` を `main` (または `master`) に設定し、Saveをクリック。
4. 数分後、生成されたURLからアクセス可能になります。
